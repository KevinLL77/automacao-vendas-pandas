# Automação de Relatórios de Vendas com Pandas 🤖

## Descrição
Projeto de automação desenvolvido em Python para otimizar a análise de dados da KL STORE. O script lê exportações diárias de vendas em formato CSV, processa os dados financeiramente e gera automaticamente um relatório gerencial em texto com o faturamento consolidado por produto.

## Tecnologias e Bibliotecas
* **Linguagem:** Python
* **Biblioteca Principal:** Pandas (DataFrames, GroupBy, manipulação de dados)
* **Outros:** Datetime (para marcação temporal dos relatórios), manipulação de ficheiros de texto e CSV.
